# 🎮 Persona 3 Reload Inspired Portfolio

Um portfólio web interativo com identidade visual e animações inspiradas na interface de usuário (**UI/UX**) de *Persona 3 Reload* — combinando cortes geométricos angulares, transições fluidas e navegação estilo menu de RPG.

> **Nota:** Projeto de portfólio pessoal focado em front-end, experiência interativa e arquitetura limpa.

## ✨ Demonstração & Inspiração

- **Demo / Deploy:** `[https://seu-usuario.github.io/seu-repositorio/]`
- **Estética e Referências:** Interface angular, transições de tela e navegação interativa inspiradas no universo de *Persona 3 Reload*.

## 🧩 Funcionalidades & Seções

- **Menu Principal Interativo:** Navegação entre seções com indicador visual ativo e transições suaves sem recarregar a página.
- **Status (Sobre Mim):** Apresentação do perfil, formação em Desenvolvimento de Software Multiplataforma e foco em desenvolvimento de software.
- **Skills:** Organização de competências técnicas (Front-end, Back-end, Banco de Dados, Ferramentas e IA) com visualização dinâmica.
- **Projects:** Vitrine de projetos com links diretos para código-fonte e demonstrações.
- **Contact:** Canais diretos para contato e redes profissionais.
